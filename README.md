# java-calculator-precourse

### 기능 목록

- 입력
    1. 입력값에 커스텀 구분자 유무를 확인한다.
        1. 커스텀 구분자가 있으면 정해진 형식에 맞게 지정되었는지 확인한다.
            1. 정해진 형식이라면 구분자를 추출한다.
            2. 아니라면 에러를 발생시킨다.
        2. 구분자가 없으면 사용자 전체 입력을 숫자 문자열로 취급한다.
    2. 숫자 문자열에 대해서 구분자를 이용해 입력값을 수열로 변환한다.
        1. 커스텀 구분자, 기본 구분자가 아닌 숫자 문자열에 대해 에러를 발생시킨다.
- 덧셈
    1. 수열의 합을 더한다.
- 출력
    1. 정해진 형식에 맞게 값을 출력한다.

### 추가 요구 사항
1. 입력
    - 수열은 최대 2억으로 제한된 숫자로 구성된다.
    - 커스텀 구분자는 최대 10개로 지정한다.
    - 입력은 `커스텀 구분자 지정` → `수열`순으로 받는다.

        ```
        입력: "//;\n1;2;3"
        출력: 6 // 설명: 1 + 2 + 3
        ```

        ```
        입력: "1;2;3//;\n"
        애플리케이션 종료 // 설명: 옳지 않은 순서
        ```

2. 커스텀 구분자
    - 커스텀 구분자는 여러 개 가능하다. 단, 최대 길이는 1로 강제한다.

        ```
        입력: "//;*\n1;2*3"
        애플리케이션 종료 // 설명: 커스텀 구분자의 최대 길이 초과
        ```

        ```
        입력: "//;\n//*\n1;2*3"
        결과: 6 // 설명: 1 + 2 + 3
        ```

    - 숫자로 기대되는 칸에 공백이 들어올 경우 0으로 취급한다.

        ```
        입력: "1, ,2"
        결과: 3 // 설명: 1 + 0 + 2
        ```

        ```
        입력: "//;\n1;;2;3"
        결과: 6 // 설명: 1 + 0 + 2 + 3
        ```

    - 커스텀 구문자가 입력된 상태에도 기본 구문자를 사용할 수 있다.

        ```
        입력: "//;\n1,2:3"
        결과: 6 // 설명: 1 + 2 + 3
        ```

    - 커스텀 구분자는 숫자가 불가능하다.

        ```
        입력: "//2\n12223"
        애플리케이션 종료 // 설명: 숫자로 커스텀 구분자 지정
        ```

    - 커스텀 구분자는 공백이 불가하다.

        ```
        입력: "// \n1 2 3"
        애플리케이션 종료 // 설명: 공백 구분자 입력
        ```

3. 숫자
    - 음수로 구성된 수열은 기대하지 않는다. 음수 입력 시 -는 구분자로 취급한다.

        ```
        입력: "//-\n1,-2,-3"
        출력: 6 // 설명: 1 + 0 + 2 + 0 + 3
        ```

        ```
        입력: "1,-2,-3"
        애플리케이션 종료 // 설명: 허용되지 않은 구분자 사용
        ```
